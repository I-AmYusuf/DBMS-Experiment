# Experiment 9 — Railway Booking Index Performance

**Aim:** Create at least 5,000 booking records, create single and composite indexes, and compare plans with EXPLAIN and EXPLAIN ANALYZE.

**Requirements:** MySQL 8.0.18+ for EXPLAIN ANALYZE.

**Expected result:** COUNT(*) returns 5000. Compare key, rows and actual execution timing before and after index creation. Actual gains depend on the data and server.
