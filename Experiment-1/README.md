# Experiment 1 — E-commerce ER Diagram

**Aim:** Design an Entity-Relationship diagram for an Indian e-commerce platform.

**Source:** `ER-Diagram.pdf` in this folder.

**Entities shown:** Customer, Address (weak entity), Order, OrderItem (weak entity), Payment, Delivery, Product, Category, Seller, and product specializations Electronics and Clothing.

**Key concepts:** Primary keys, composite and multi-valued attributes, weak entities, relationships, cardinality, and specialization.

**Note:** This folder contains the original uploaded ER diagram PDF. Experiment 2 converts the ER model into relational tables and SQL constraints.
