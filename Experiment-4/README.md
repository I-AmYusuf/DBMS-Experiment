# Experiment 4 — Joins, Subqueries and Set Operations

**Aim:** Practice INNER JOIN, LEFT JOIN, self-join, three-table joins, correlated subqueries, EXISTS, simulated INTERSECT/EXCEPT, and EXPLAIN.

**Prerequisite:** Run Experiment 3 first.

**Note:** INTERSECT and EXCEPT are simulated with EXISTS/NOT EXISTS for MySQL 8.0 compatibility.

**Expected result:** Related employee, department and project rows are joined; subqueries identify employees above their department average and employees without assignments.
