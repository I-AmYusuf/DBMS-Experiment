## How to run
1. Install MySQL 8.0+ and open MySQL Workbench.
2. Open the `experiment.sql` file inside the required experiment folder.
3. Execute statements in order. Experiments 4–6 depend on the EmployeeManagement schema from Experiment 3.
4. Some statements intentionally demonstrate errors; run those separately as instructed in comments.

Educational sample data only. Review each README before execution.
